# Debug Prompt

Start an evidence-driven bug investigation and repair.

Read Workflows/processes/bugfix.md, Workflows/skills/debugging/SKILL.md, and Workflows/skills/testing/SKILL.md when verification is needed. Read Workflows/tasks/CURRENT.md and relevant project context only as required.

Understand expected versus actual behavior, gather evidence, reproduce the issue when possible, inspect relevant code, logs, errors, and output, form and test hypotheses, and identify the root cause where possible.

Avoid random trial-and-error edits. Implement the smallest safe fix, verify the original issue, run relevant regression checks, review the diff, and update task, state, or handoff information when necessary.
