# Review Prompt

Review the current implementation before considering the task complete.

Read Workflows/tasks/CURRENT.md, the relevant implementation or diff, and Workflows/skills/code-review/SKILL.md. Load Workflows/skills/testing/SKILL.md when verification results or additional checks need review.

Check correctness against the task, missing requirements, unintended behavior changes, architecture consistency, unnecessary complexity, duplication, security or privacy risks, edge cases, verification quality, unrelated edits, debug artifacts, and silent removal of existing behavior.

Report meaningful findings by priority. Check whether Workflows/tasks/CURRENT.md, Workflows/STATE.md, or Workflows/context/HANDOFF.md needs an update based on the review. Do not update workflow documentation automatically when nothing meaningful changed.
