# Plan Task Prompt

Turn the user's development request into a clear active task without automatically implementing it.

Read the relevant project context and inspect the relevant repository areas when necessary. Identify the scope, affected files or components, confirmed requirements, constraints, uncertainties, expected behavior, verification approach, and completion criteria.

Preserve unresolved questions instead of inventing answers. Use Workflows/templates/TASK-TEMPLATE.md as optional structural guidance, then populate or update Workflows/tasks/CURRENT.md.

Keep broader project knowledge in Workflows/PROJECT.md, current project condition in Workflows/STATE.md, and permanent agent rules in Workflows/RULES.md. Do not implement the task unless implementation was explicitly requested as part of the same operation.
