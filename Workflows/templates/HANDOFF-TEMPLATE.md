# Handoff Template

> Use this structure when unfinished work must continue in another session, agent, or machine.
>
> Keep it aligned with Workflows/context/HANDOFF.md. Record only information needed to continue.

## Current Task

Identify the active task or reference Workflows/tasks/CURRENT.md.

-

## What Was Done

Summarize meaningful work completed so far.

-

## Current Status

Describe the exact condition when work stopped.

-

## Files Changed

List files meaningfully changed during the unfinished work. Do not replace Git status or a complete diff.

-

## Important Findings

Record discoveries the next agent needs to know.

-

## Checks Completed

Record verification already performed.

-

## Checks Remaining

Record verification still required.

-

## Blockers

Record anything preventing progress. Use “None known.” when appropriate.

None known.

## Exact Next Action

State one concrete, immediately actionable next step. Avoid vague instructions such as “continue the work.”
